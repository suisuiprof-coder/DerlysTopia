DerlysTopia Android project (prototype)

Cara build APK:
1. Upload folder project ini ke repository GitHub (branch main).
2. Buka tab Actions.
3. Pilih workflow "Build DerlysTopia APK".
4. Tekan Run workflow.
5. Setelah selesai, buka hasil workflow dan download artifact "DerlysTopia-debug-apk".
6. Ekstrak artifact, lalu install app-debug.apk di Android (aktifkan izin install aplikasi dari sumber ini bila diminta).

Alternatif:
Buka project ini di Android Studio, lalu pilih Build > Build APK(s).

Catatan:
- Ini APK debug prototype, belum ditandatangani untuk distribusi Play Store.
- Game masih single-player prototype berbasis WebView; multiplayer/backend belum ada.
